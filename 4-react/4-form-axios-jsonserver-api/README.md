# Form

- React'ta formlar verilen yönetilme biçimine göre 2'ye ayrılır

## Controlled Form

- Form içindeki bütün inputlardaki veriler state'de tutulur
- Daha fazla kod yazarız ama anlık girdiyi takip ettiğimiz için form validasyonu yapma imkanı sunra

## Uncontrolled Form

- Inputlardaki veriler state'de tutulmaz form gönderilince erişilir
- Daha az kod yazarız ama anlık girdi takip edemeyeceğimiz için anlık hata kontrolü yapılamaz
